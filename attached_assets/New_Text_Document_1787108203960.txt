==================================================
18. TALABAT BETAK DELIVERY
==================================================

If Restaurant chooses Talabat Betak delivery:

The platform automatically searches for the nearest AVAILABLE Talabat Betak driver.

Driver assignment workflow:

Restaurant requests Talabat Betak delivery
        ↓
Find nearest available driver
        ↓
Send delivery offer
        ↓
Driver accepts?
        |
   ┌────┴────┐
   YES       NO
    |         |
 Assigned   Find next nearest driver
              |
              ↓
        Continue until accepted
        or no driver available

Drivers can reject delivery offers.

If Driver A rejects:

Driver B is considered.

If Driver B rejects:

Driver C is considered.

Continue according to availability and assignment rules.

This logic MUST be implemented server-side.

Avoid race conditions where multiple drivers accept the same delivery.

Use proper locking/transaction/assignment mechanisms.
